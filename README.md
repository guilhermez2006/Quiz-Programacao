# Quiz de Programação

Um projeto simples de quiz interativo em JavaScript para testar conhecimentos básicos de programação.

## ✨ Sobre

Este projeto exibe um quiz de perguntas sobre JavaScript diretamente no navegador.
Cada pergunta oferece múltiplas opções e mostra o resultado final ao término do quiz.

## 🧩 Tecnologias

- HTML
- CSS
- JavaScript

## 🚀 Como usar

1. Abra o arquivo `index.html` no seu navegador.
2. Responda às perguntas clicando nas opções.
3. Aguarde o resultado final ser exibido.
4. Clique em `Jogar Novamente` para reiniciar o quiz.

## 📝 Estrutura do projeto

- `index.html` - estrutura principal da página.
- `src/style.css` - estilos visuais do quiz.
- `src/script.js` - lógica do quiz e gerenciamento de perguntas.

## 🎯 Recursos

- Perguntas com múltiplas opções.
- Feedback visual para resposta certa e errada.
- Contador de progresso.
- Resultado final com pontuação.
- Botão para reiniciar o quiz.

## 💡 Personalização

Você pode facilmente:

- adicionar novas perguntas em `src/script.js` dentro do array `perguntas`;
- alterar o estilo visual em `src/style.css`;
- ajustar o tempo de transição entre perguntas em `setTimeout`.
